【占位说明，正式使用前请删除这里的全部内容】
本文件为功能模板，使用 `{{ }}` 包裹的内容为待填写占位符。
通用占位符：
  {{TARGET_OBJECT}}     目标天体名称（主名称、别名或 object_id）
  {{TARGET_SYSTEM}}     目标所属行星系统名称，可留空表示不限
  {{DIMENSIONS}}        需要生成的扩展维度，多项用顿号分隔
  {{DEPTH}}             详细程度：简略 / 标准 / 详尽
  {{STYLE}}             文风与世界观基调
  {{LENGTH}}            字数或篇幅要求
  {{USER_SETTING}}      用户设定文档中的相关约束或需要沿用的名词
  {{EXTRA}}             其他补充约束，无则留空

以下内容为示例模板，使用时请根据需要修改

# 模板一：通用扩展信息生成

请为天体 {{TARGET_OBJECT}} 生成扩展信息。

- 所属系统：{{TARGET_SYSTEM}}
- 生成维度：{{DIMENSIONS}}
- 详细程度：{{DEPTH}}
- 文风基调：{{STYLE}}
- 篇幅要求：{{LENGTH}}
- 沿用设定：{{USER_SETTING}}
- 补充约束：{{EXTRA}}

执行要求：
1. 先确认 {{TARGET_OBJECT}} 的存在性与唯一性；若返回多个候选，列出候选并请我确认，不要自行选定；若不存在，直接说明并结束。
2. 取得该天体的实测数据后，先判断哪些维度具备生成条件、哪些因数据缺失而不适合展开。对不具备条件的维度，说明原因，不要强行编造。
3. 每个维度按"结论、依据、细节"的顺序组织；依据中需要引用实测数值时原样引用，并标注来源等级。
4. 各维度之间必须相互自洽，并与此前已生成的内容保持一致。
5. 结尾给出"自检"小节，列出本次核对的关键点。


# 模板二：矿产资源生成

请为天体 {{TARGET_OBJECT}} 生成矿产资源设定。

- 所属系统：{{TARGET_SYSTEM}}
- 星球类型与基本参数：依据实测数据自行判定并在开头复述
- 需要覆盖的内容：{{DIMENSIONS}}
- 详细程度：{{DEPTH}}
- 沿用设定：{{USER_SETTING}}
- 补充约束：{{EXTRA}}

生成时必须满足：
1. 矿产种类与丰度需与该天体的类型、质量、内部结构、表面温度、大气与水圈条件相符；无大气、无水圈、无地质活动的天体，不得出现依赖这些条件的沉积型或水成型矿产。
2. 按"矿产名称（化学式或主要成分）、赋存形式、主要产地或分布规律、开采难度、工业用途"的字段组织；条目较多时用表格。
3. 丰度、品位、储量一律给出量级或区间，并标注【推定】或【虚构】，不要给出貌似精确的实测式数值。
4. 不得与实测数据矛盾；若某类矿产的存在需要额外前提（如曾经存在液态水、曾发生过重大撞击），需显式写出该前提。


# 模板三：文明形态生成

请为天体 {{TARGET_OBJECT}} 生成文明设定。

- 所属系统：{{TARGET_SYSTEM}}
- 文明类型或发展阶段：{{DIMENSIONS}}
- 详细程度：{{DEPTH}}
- 文风基调：{{STYLE}}
- 沿用设定：{{USER_SETTING}}
- 补充约束：{{EXTRA}}

生成时必须满足：
1. 先论证承载条件：依据实测的半径、表面重力、温度、大气成分与压强、水圈、生物圈数据，说明该天体是否具备承载所设定文明的基础条件；不满足时，说明该文明需要何种技术或改造手段才能存在。
2. 文明的核心特征（生理形态、社会结构、技术水平、能源与资源基础、文化特征）必须与其环境条件和可再生资源相符，例如无氧大气下不得出现依赖呼吸自由氧的生理设定，低重力下的结构尺度需相应放大。
3. 需要与矿产资源、生态系统等已生成内容相互引用时，保持一致。
4. 涉及用户设定文档中的专有名词、历史事件、政体名称时，原样沿用。
5. 结尾说明该文明设定与实测数据之间是否存在需要用户裁决的冲突。


# 模板四：宜居度评价

请评价天体 {{TARGET_OBJECT}} 的宜居度。

- 所属系统：{{TARGET_SYSTEM}}
- 评价口径：{{DIMENSIONS}}
- 详细程度：{{DEPTH}}
- 参照标准或阈值：{{USER_SETTING}}
- 补充约束：{{EXTRA}}

评价要求：
1. 先复述用于评价的实测数据（半径、质量、表面重力、表面温度、大气压强与成分、水圈、生物圈、母星光度与轨道距离等），数据缺失的项明确列为缺失。
2. 逐项打分：对每个评价维度给出"维度名称、实测依据、评分、评分理由"，并说明所用阈值或参照标准来自何处；未指定的阈值需显式标明为自定义口径。
3. 必须给出综合结论，包括综合评分或等级、主要宜居优势、主要限制因素（至少两项）、以及评分对数据缺失与假定的敏感程度。
4. 区分"对已知地球型生命宜居"与"对广义生命宜居"两种口径，用户未指定时按前者评价，并在开头写明所采用的口径。
5. 不做超出数据的断言，不因数据不足而给出虚假的确定性结论。


# 模板五：自定义设定文档应用

请在已有设定文档的约束下，为天体 {{TARGET_OBJECT}} 生成 {{DIMENSIONS}}。

- 所属系统：{{TARGET_SYSTEM}}
- 需要沿用的设定条目或名词：{{USER_SETTING}}
- 详细程度：{{DEPTH}}
- 补充约束：{{EXTRA}}

执行要求：
1. 先确认目标天体的实测数据，再依据设定文档确定需要在设定框架内解释的部分。
2. 设定文档与实测数据冲突时，实测数据保持不变，并把设定文档中的说法改写为该世界观内部的"记载、传说或观测误差"。
3. 生成内容中出现的专有名词必须与设定文档完全一致，不得新造同义名称；确需新增名词时，单独列出并说明理由。
4. 不得引入设定文档未提及且与既有世界观明显冲突的新势力、新历史或新物理规律。
5. 结尾列出本次实际用到的设定条目，以及仍有歧义、需要我补充确认的部分。
