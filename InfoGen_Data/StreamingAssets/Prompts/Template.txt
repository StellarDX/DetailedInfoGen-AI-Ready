# 模板一：矿产资源生成

请为天体 {TARGET_OBJECT} 生成矿产资源设定。

- 所属系统：{TARGET_SYSTEM}
- 星球类型与基本参数：依据实测数据自行判定并在开头复述
- 需要覆盖的内容：{DIMENSIONS}
- 详细程度：{DEPTH}
- 沿用设定：{USER_SETTING}
- 补充约束：{EXTRA}

输出维度：
1. 标题
2. 行星基本数据，来自数据库，简略输出即可
3. 矿物列表，按"矿产名称（化学式或主要成分）、赋存形式、主要产地或分布规律、开采难度、工业用途"的字段组织；条目较多时用表格。

生成时必须满足：
1. 矿产种类与丰度需与该天体的类型、质量、内部结构、表面温度、大气与水圈条件相符；无大气、无水圈、无地质活动的天体，不得出现依赖这些条件的沉积型或水成型矿产。
2. 丰度、品位、储量一律给出量级或区间，不要给出貌似精确的实测式数值。
3. 不得与实测数据矛盾；若某类矿产的存在需要额外前提（如曾经存在液态水、曾发生过重大撞击），需显式写出该前提。
4. 不能出现「输出维度」以外的输出，无需显式标注来源及一致性说明，保存干净输出


# 模板二：文明设定生成

请为天体 {TARGET_OBJECT} 生成文明设定。

- 所属系统：{TARGET_SYSTEM}
- 文明类型或发展阶段：{DIMENSIONS}
- 详细程度：{DEPTH}
- 文风基调：{STYLE}
- 沿用设定：{USER_SETTING}
- 补充约束：{EXTRA}

输出维度：
1. 标题
2. 行星基本数据，来自数据库，简略输出即可
3. 生物圈编年史，包含从行星形成到文明诞生的这段时间，表格呈现，以log(年)为年代标尺
4. 文明的核心特征（生理形态、社会结构、技术水平、能源与资源基础、文化特征），必须与其环境条件和可再生资源相符，例如无氧大气下不得出现依赖呼吸自由氧的生理设定，低重力下的结构尺度需相应放大。
5. 文明诞生后进入关键时代的时间节点，表格呈现，以log(年)为年代标尺

生成时必须满足：
1. 需要与矿产资源、生态系统等已生成内容相互引用时，保持一致。
2. 涉及用户设定文档中的专有名词、历史事件、政体名称时，原样沿用。
3. 不能出现「输出维度」以外的输出，无需显式标注来源及一致性说明，保存干净输出


# 模板三：宜居度评价

请评价天体 {TARGET_OBJECT} 的宜居度。

- 所属系统：{TARGET_SYSTEM}
- 评价口径：{DIMENSIONS}
- 详细程度：{DEPTH}
- 参照标准或阈值：{USER_SETTING}
- 补充约束：{EXTRA}

输出维度：
1. 标题
2. 行星基本数据（半径、质量、表面重力、表面温度、大气压强与成分、水圈、生物圈、母星光度与轨道距离等），数据缺失的项明确列为缺失。
3. 宜居度评级及理由，以表格形式呈现。内容：
  1. 综合结论：包括综合等级（A-F）、主要宜居优势、主要限制因素（至少两项）、以及评分对数据缺失与假定的敏感程度。
  2. 逐项打分：对每个评价维度给出"维度名称、实测依据、评分（A-F）、评分理由"，并说明所用阈值或参照标准来自何处；未指定的阈值需显式标明为自定义口径。

评价要求：
1. 区分"对已知地球型生命宜居"与"对广义生命宜居"两种口径，用户未指定时按前者评价，并在开头写明所采用的口径。
2. 不做超出数据的断言，不因数据不足而给出虚假的确定性结论。
3. 不能出现「输出维度」以外的输出，无需显式标注来源及一致性说明，保存干净输出
