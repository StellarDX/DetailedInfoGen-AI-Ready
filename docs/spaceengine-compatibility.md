# SpaceEngine 真实导出回归范围

本次仅为维护建立小型真实 fixture 和测试入口，不增加版本特判或新的物理模型。

独立本地维护实验曾对 SpaceEngine `0.991.50.2155 beta` 的 11 个真实文件、1891 个对象执行全批检查；5 个完整根输入的 1885 个对象通过该维护实现的 native、数据库和查询链。另六个缺宿主片段只通过解析，不能进入完整 system pipeline。该历史证据来自包含其他修复的维护实现，不等于本测试基座已经证明未经修复的 upstream 全链路通过。

参考维护基线的受限声明是：“已验证兼容 SpaceEngine 0.991.50.2155 beta 本批真实语料中具备完整系统根节点的导出。”

本候选只携带两个单恒星根和一个缺宿主行星片段，均为原样副本。版本由导出批次声明及运行日志确认，文件自身没有版本头。大型语料和验收日志保留在本地；不将人工构造数据标为 real。

缺宿主 fragment 不在当前完整系统输入范围内；缺少 AccretionDisk、真实重复 Life/Ocean 等是覆盖边界；没有确认同源的 0.990↔0.991 系统配对，因此不能宣称所有版本字段完全等价。这三项不作为当前已确认 bug，不补造宿主，也不为版本号修改代码。
